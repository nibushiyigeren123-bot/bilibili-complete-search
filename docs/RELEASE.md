v1.1.1：修复综合页的视频空位，以及「重新核验」点击后没有变化的问题。

- 正确隐藏综合搜索页的卡片外层列容器，合格视频按连续网格排列到前面。
- 综合页视频区域支持后续页补充，用户、直播、番剧模块保持原样。
- 手动重新核验跳过成功标签缓存，显示进度和核验次数；仍遵守风控冷却。
- 忽略 B站自动追加的 vt 等跟踪参数，避免核验反馈与补充结果被重置。
- 加强面板鼠标交互保护，并显示扩展版本。

以下功能继续保留：

合并视频标题与真实标签，只显示完整覆盖搜索词的结果。

- 中文与数字完整匹配，如「黑色行动7」「BO7」。
- 英文灵活词块匹配，如 `payday` 可匹配 `pay … day`。
- 开关、实时统计、翻页跟踪、失败原因与重新核验。
- 视频搜索结果不足一页时，保留原搜索词、排序和筛选条件，读取后续页并核验后补入当前列表。
- 每轮最多补读 5 个后续页，达到一页数量或最后一页时停止；支持继续补充、暂停补充。
- 修复 B站按卡片原始序号隐藏部分卡片时，合格结果和补充视频仍可能不可见的问题。
- 去除重复视频；关闭过滤恢复当前页原始结果；切换搜索词或翻页时清除旧补充结果。
- 接口失败、风控或标签待核验时暂停补充，不绕过验证。
- 手动安装：下载 ZIP → 解压 → Chrome 开发者模式 → 加载 `extension` 文件夹。
- AI 辅助安装：仓库 `docs/AI-INSTALL.md` 与 `scripts/install.ps1`。

`bilibili-complete-search-v1.1.1.zip` 是扩展安装包。无需 Node 或 Python。

已有用户：将新版 extension 内文件更新到原安装目录，在 chrome://extensions 点击该扩展的重新加载，再刷新 B站搜索页。确认右下角面板显示 v1.1.1。也可以移除旧扩展后重新加载新版目录。

项目提供手动安装步骤、AI 安装提示词和 Windows 安装脚本。展示视频由创作者发布到 B站。

只筛选 B站已返回的视频；建议使用视频搜索标签。详细规则、权限及源代码见仓库 README。
