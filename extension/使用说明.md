# B站搜索 · 完整包含

## 安装到 Chrome

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择当前这个目录，目录内应该直接有 `manifest.json`。
   例如选择：`C:\Tools\bilibili-complete-search\extension`。
   若使用压缩包，先解压，再选择其中的 `extension` 文件夹。
5. 打开或刷新 B站视频搜索页，例如 https://search.bilibili.com/video?keyword=payday 。

右下角出现“B站搜索 · 完整包含”即表示页面脚本已经加载。扩展没有发布到 Chrome 商店，无需购买或账户授权。以后请保留安装目录；修改代码后，在 Chrome 扩展管理页点“重新加载”，再刷新 B站页面。

## 过滤规则

只使用视频标题和真实视频标签。简介、UP 主昵称、评论、播放量不算匹配依据。

- 中文连续片段、数字连续片段都必须完整出现，片段之间的先后顺序不限。
- 英文忽略大小写。允许拆成多个连续词块，每个拆开的词块至少两个字母。词块可在标题、不同标签中分别出现，顺序不限。
- 同一段文本不能重复使用来凑够重复的搜索内容。
- 全角英文和数字会规范化；搜索词中的空格和标点用作分隔。
- 这是文本词块匹配，不是词典分词；例如 `pa + yday` 也会满足 `payday`。
- 搜索单个英文字母仍可正常匹配；较长英文查询不允许靠单字母碎片凑齐。

| 搜索 | 标题 | 标签 | 结果 |
| --- | --- | --- | --- |
| 黑色行动7 | 黑色行动玩法 | 7 | 保留 |
| 黑色行动7 | 版本7 | 黑色行动 | 保留 |
| 黑色行动7 | 黑色行动玩法 | 无关 | 隐藏 |
| 黑色行动7 | 黑色行动 版本6 | 无关 | 隐藏 |
| payday | PAYDAY 3 攻略 | 无关 | 保留 |
| payday | pay … day | 无关 | 保留 |
| payday | day 攻略 | pay | 保留 |
| payday | pay 攻略 | 无关 | 隐藏 |
| payday | p … a … y … d … a … y | 无关 | 隐藏 |

标题已经完整满足查询时会直接保留，免去不必要的标签请求。否则读取标签，与标题合并核验。标签缓存有效期为 24 小时。

## 页面操作

- **保留**：已确认完整包含。
- **隐藏**：标题和标签合起来仍缺内容。
- **核验中**：标签请求排队或进行中，先隐藏。
- **待核验**：接口失败或视频编号无法识别，先隐藏，并显示失败原因。
- **关闭过滤**：立即恢复 B站原始结果；重新开启可继续过滤。
- **重新核验**：重新评估当前已加载视频，跳过标签缓存重新读取，显示核验进度与次数；风控冷却期间仍会显示限制原因。
- **自动补充**：视频搜索页或综合页视频区域的合格结果不足原一页数量时，读取后续页，核验后补到当前列表。保留原排序和筛选条件，去除重复视频。
- **继续补充 / 暂停补充**：每轮最多读取 5 个后续页，达到一页数量或最后一页时停止；可手动继续或暂停。每批的合格视频都会保留，最终数量可能略超过一页。

关闭过滤会移除补充结果并恢复当前页的原始列表。搜索词、排序、筛选条件或页码变化时，旧补充结果会清除并重新核验。B站底部页码仍对应原始搜索页，不是过滤后的页码。接口失败、风控或标签待核验时暂停补充并显示原因。

搜索词、排序、筛选或页码改变时会自动核验；B站自动追加的 vt 等跟踪参数不触发重置。统计只包含当前已经加载的视频，并非 B站总结果数。支持“视频”搜索标签与“综合”页的视频区域；用户、直播、番剧等非视频模块不属于过滤范围。右下角显示扩展版本，更新后应看到 v1.1.1。

## 实际范围和权限

此扩展过滤 B站已经返回的视频，无法找回 B站没有召回的内容。只在 `search.bilibili.com` 注入脚本，并使用 `api.bilibili.com` 的视频搜索与标签接口；不申请所有网站、浏览记录、下载或 Cookie 读取权限。请求可使用浏览器已有的 B站登录状态。不上传搜索词到第三方，不包含远程执行代码。后续页也没有合格视频时，列表仍可能为空，不会放宽规则填入不匹配的内容。

遇到 B站风控（如 HTTP 412、429）会暂停新的标签网络请求约一分钟，未确认的结果保持隐藏。可稍后点击“重新核验”，或暂时关闭过滤查看原始结果。扩展不会自动登录或绕过验证码。

## 开发与验证

扩展本身没有运行时 npm 依赖。源代码、测试和浏览器验证记录保留在上级项目目录。

- `npm ci` 然后 `npm test`：匹配、页面更新、接口失败、缓存测试。
- `node tests/verify-browser.cjs`：用本机 Edge 的 Chromium 内核和独立配置验证真正的扩展加载，再访问真实 B站搜索页；不使用个人浏览器配置。

采用 Manifest V3，跨域标签请求放在后台 service worker，符合 [Chrome 跨域网络请求文档](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)。本地加载步骤见 [Chrome 官方教程](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。
